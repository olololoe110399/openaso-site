# OpenASO GitHub Pages

## Before publishing
Replace every occurrence of `buinguyenqueanh1103@gmail.com` with your support email.

## Publish
1. Create a public GitHub repository, such as `openaso-site`.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

URLs:
- Privacy: `https://YOUR_USERNAME.github.io/openaso-site/privacy/`
- Support: `https://YOUR_USERNAME.github.io/openaso-site/support/`

Use those URLs in App Store Connect.

Review the privacy claims before publishing if your app uses analytics, crash reporting, cloud sync, accounts, a proxy server, or any third-party SDK that processes data.
